# TRUE LIFE — Chapter Two

A mobile-first single-player life simulator. Choose a character, make decisions, and age through school, jobs, relationships, money, homes, health, and random events.

## Play
Visit the TRUE LIFE Vercel deployment URL, start a life, and use the six tabs. Press **Age Up** to advance a year. Each year offers three major actions.

## Technology
Static HTML, CSS, and vanilla JavaScript. No build process or account is required. Your game saves locally in your browser. Back up important progress with the in-game JSON export.

## Deployment
This is a standalone subdirectory of the repository. The Vercel project **true-life-simulator** is configured with Root Directory = `true-life` so the other game is not replaced.

## Notes
Financial, medical, and career mechanics are fictional and simplified for gameplay.
